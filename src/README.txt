M5 Team Project: Program (Week 13)
Vending Machine Simulation

Files included:
- Main.java
- Item.java
- VendingMachine.java
- VendingMachine.output

How to run:
1. Place Main.java, Item.java, and VendingMachine.java in the same Java project/source folder.
2. Compile and run Main.java.
3. Compare the output to VendingMachine.output.

Purpose:
This program demonstrates three ways to solve the same vending machine inventory/search problem:
1. Array-based implementation
2. ArrayList-based implementation
3. HashMap-based implementation
